A modern full-stack web application that connects customers with trusted home service providers. Workly makes it easy to discover, book, and manage household services such as plumbing, electrical work, carpentry, painting, AC repair, cleaning, and more.

🌐 **Live Demo:** https://workly-home.vercel.app/

🔗 **GitHub Repository:** https://github.com/Sathirasugeesvara/Workly

---

## ✨ Features

- 🔐 Secure JWT Authentication
- 👤 Customer, Service Provider & Admin Roles
- 🏠 Browse Home Services
- 📅 Book Services
- 👨‍🔧 Find Trusted Service Providers
- ⭐ View Provider Profiles
- 🤖 AI Assistant for Home Service Guidance
- 📱 Fully Responsive Design
- ☁️ MongoDB Atlas Cloud Database
- 🔒 Secure REST API with Spring Security
